# Changelog

## 1.0.0 — 2026-09-05

- Standalone GA LAB repository verification product.
- SHA-bound JSON/Markdown verification reports.
- Fail-closed `SAFE_TO_MERGE`, `BLOCKED`, and `UNKNOWN` verdicts.
- Configured command verification without shell execution.
- Protected-path and test-weakening policy checks.
- Report integrity validation against the current Git HEAD.
- Test suite, Dockerfile, CI, security and release documentation.
- Automated GitHub Release publishing with wheel/source artifacts and SHA-bound evidence.
- GitHub Container Registry package publishing with versioned and `latest` image tags.
- Public SCP-origin statement and project contact details.
